# AdaSouls Cardano Governance

How AdaSouls takes part in Cardano governance, in the open.

- **AdaSouls DRep.** Every vote comes with a published rationale and the analysis behind it. An AI agent prepares the analysis; a named human decides and signs. See [how we use AI](policies/ai-use.md) and our [conflict of interest policy](policies/conflict-of-interest.md).
- **SOULS stake pool.** The pool votes on the actions open to stake pool operators, with the same process.
- **Votes and rationales:** [votes/](votes/README.md).
- **Tools** in this repo: the analyst, voting tools, a delegation concierge and a treasury milestone verifier. They're built in stages; see [docs/PLAN.md](docs/PLAN.md).
