# How AdaSouls uses AI in governance

- An AI agent reads each governance action, its documents, the Cardano Constitution and the proposer's record, and writes an analysis with the arguments for and against.
- A named human, Matías Falcone, reads the analysis, decides, and signs every vote with a hardware wallet. The AI never holds the DRep key or the stake pool's keys.
- The analysis is published with the vote, as it stood when the decision was made, and signed so that it can't be changed afterwards without anyone noticing.
- Text inside proposals is treated as data, never as instructions to the AI.
- When the human disagrees with the analysis, the rationale says so and why.
- If this process changes, we update this page and our DRep metadata.
